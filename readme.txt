Retail Sales Data Analysis Project

Objective : The objective of this project is to analyze retail sales data using Python and visualize important business insights.
Tools and Libraries Used :
> Python
> Pandas
> Matplotlib
> Seaborn
Dataset Used :
Sample Superstore Dataset
Features of the Project :
> Data loading and analysis
> Sales analysis by category
> Profit analysis
> Data visualization using graphs
Conclusion :
This project helped in understanding retail sales trends and profit distribution across categories. Python libraries made data analysis and visualization easier and more effective.
